Artifact Review

My artifact is an Android inventory tracking application built with Java that applies all required enhancements for the capstone project. It allows the user to add new items to a database, delete items, update items by quantity, and read items in a grid view. Along with SMS permissions to send messages to the user if an inventory item is out of stock. The enhancements add additional features for sorting and searching through inventory.
